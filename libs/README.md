# Local build dependency / 本地构建依赖

`ponder-legacy-1.7.1.jar` is required by the current Gradle build for the optional Ponder integration. It is used as a compile/development dependency and is not embedded in the Cogwork Bridge release JAR. Players install Ponder Legacy separately to enable tutorials.

Upstream: https://github.com/mcyudream/ponder-legacy

SHA-256: `923CB6653EEE53C96E4FBD9AC871C897CB151B91B3E0759C40ED4687611C6DD4`
